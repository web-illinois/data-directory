Unit Administration Overview

Summary

Unit administrators manage the unit and the offices inside it.

Requires unit administrator access.

Unit menu

Page Purpose
General Information Edit the unit's general details. See Edit Unit General Information.
Add and Remove Offices Add new offices to the unit or remove existing ones.
Unit Administrators Manage who can administer the unit. See Manage Unit Administrators.
Internal Information Notes, publishing, profile loading, images, and user instructions. See Edit Unit Internal Information.
Tag Information Manage tags. See Manage Unit Tags.
Links to Pull Information Links for accessing unit data through the API. See Links to Pull Directory Information.

Extra office pages for unit administrators

Unit administrators also see Internal Information and Links to Pull Information in the Office Administration menu.
