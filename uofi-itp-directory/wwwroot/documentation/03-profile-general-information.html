Edit Your General Profile Information

Summary

The General Information page contains your name, pronouns, location, address, and alternate contact details.

Path: Edit My Profile > General Information

Steps

  1. From the home page, select Edit on the Edit My Profile card.
  2. Update the fields described below.
  3. Scroll to the bottom and select Save.

Fields

Preferred Name

  • First Name and Last Name - if left blank, the directory uses the name from My UI Info.

Preferred Pronouns

  • Choose a template (he/him, she/her, they/them) or type your own in the Pronouns field.
  • Pronoun disclosure is an individual choice and not a mandate.

Office Information

  • Room Number and Building.

Office Address

  • Address Line 1, Address Line 2, City, State, and Zip Code.
  • If left blank, the address from My UI Info is used.
  • Hide Address - select this to not display your address, even if one is listed in My UI Info.

Alternate Contact Information

Additional contact fields appear below the address section.

Information from My UI Info

Some information can be edited in My Profile in My UI Info, and it will update your directory information as well.

  • Changes in My UI Info take a few days to process.
  • To force a refresh, select Save at the bottom of the General Information page.
