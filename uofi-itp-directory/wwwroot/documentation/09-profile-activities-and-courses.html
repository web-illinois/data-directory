Add Activities and Courses

Summary

Add publications, presentations, history, and course information to a profile.

Activities

Path: Profile Administration > Activities

Each activity has:

  • Title (required)
  • Url
  • Year Started and Year Ended
  • Type

Contact your office administrator for guidance on what type of information belongs here.

If you use Illinois Experts

If your activities are managed in Illinois Experts, the page links to it instead. Make changes there, then select Refresh Directory Entry to force an update. See Using Illinois Experts with Your Profile.

Courses

Path: Profile Administration > Courses

Each course has:

  • Rubric and Course Number
  • Display Order
  • Title (required)
  • Url

Load from Campus

After entering the rubric and course number, select Load from Campus to fill in course information from the campus database.

Automatic course loading

For some units, course information is loaded automatically from the WIGG Course Repository using a "best-guess" process. For more control:

  1. Select Load Default Courses at the bottom of the page.
  2. Edit the loaded courses as needed.
  3. To return to the default behavior, remove all of your courses.

Remember to save your changes before leaving the page.
