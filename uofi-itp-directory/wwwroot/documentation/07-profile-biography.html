Edit Your Biography

Summary

Add a professional biography to a profile.

Path: Profile Administration > Biography

Important: The biography is displayed on a public website. Do not include personal information such as phone numbers or home addresses.

Edit the biography

  1. Open Biography from the left menu.
  2. Type in the editor. Available formatting:
    • Bold, italic, underline, strikethrough
    • Links
    • Bulleted and numbered lists, with indent controls
  3. Select Save.
  4. Use the preview button to see how the profile looks.

Contact your office administrator if you are unsure what type of information belongs here.

If your biography is managed in Illinois Experts

Some people maintain their biography in Illinois Experts instead. In that case the Biography page shows a link to Illinois Experts instead of an editor.

  • Make your edits in Illinois Experts.
  • Directory updates are not immediate and can take a few days.
  • To force an update, select Refresh Directory Entry.

See Using Illinois Experts with Your Profile.
