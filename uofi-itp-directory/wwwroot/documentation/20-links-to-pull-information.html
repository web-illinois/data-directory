Links to Pull Directory Information (API)

Summary

Your office information is available through an Application Programming Interface (API), so other campus systems can use it.

Path: Office Administration > Links to Pull Information

Requires unit administrator access.

Two ways to access information

  • By ID - an ID was assigned when your office was created.
  • By Code - a unique code you create. This is often more memorable than the ID.

Steps

  1. Open Links to Pull Information.
  2. Select Link to get information by ID to open your office data.
  3. To use a code, enter an Internal Code and select Save. A Link to get information by Code button then appears.

If no code has been entered, the page prompts you to add one.

Notes

  • The internal code is sent to the API instead of the office ID.
  • Use Clear Cache after saving if the change does not appear right away.
