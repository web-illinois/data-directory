# Unit Administration Overview

## Summary

Unit administrators manage the unit and the offices inside it.

*Requires unit administrator access.*

## Unit menu

| Page | Purpose |
| --- | --- |
| General Information | Edit the unit's general details. See [Edit Unit General Information](22-unit-general-information.md). |
| Add and Remove Offices | Add new offices to the unit or remove existing ones. |
| Unit Administrators | Manage who can administer the unit. See [Manage Unit Administrators](24-unit-administrators.md). |
| Internal Information | Notes, publishing, profile loading, images, and user instructions. See [Edit Unit Internal Information](23-unit-internal-information.md). |
| Tag Information | Manage tags. See [Manage Unit Tags](18-unit-tags.md). |
| Links to Pull Information | Links for accessing unit data through the API. See [Links to Pull Directory Information](20-links-to-pull-information.md). |

## Extra office pages for unit administrators

Unit administrators also see **Internal Information** and **Links to Pull Information** in the Office Administration menu.
