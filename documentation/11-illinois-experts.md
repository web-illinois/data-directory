# Using Illinois Experts with Your Profile

## Summary

[Illinois Experts](https://experts.illinois.edu/) is a campus-wide web profile system for university researchers. Tenure-system faculty are given accounts automatically. Accounts for specialized faculty may be available by request (see [Illinois Experts Help & FAQs](http://go.illinois.edu/experts)).

If you use Illinois Experts, your biography and activities are managed there and copied to the directory.

## Log in and edit

1. Go to the [Experts Login page](https://go.illinois.edu/experts-login).
2. Select **My Profile** to edit details such as education history and biography.
3. Or select **Add New** to add activities such as publications, presentations, editorships, and awards.

## Data you add that is copied to your profile

| Directory section | Where to add it in Illinois Experts |
| --- | --- |
| Biography | Profile Information > **Professional Information** or **Personal Profile**. If both are filled out, Professional Information is used. |
| Key Professional Appointments | **Organizational Affiliations** (University of Illinois background) or **External positions** (outside background). |
| History | Profile Information > **Education**. Do not use "Education/Academic qualification". |
| Awards | Profile Information > **Honors & Awards**. Each line becomes an individual award. |
| Links | **Links** section. Links marked Twitter or LinkedIn show as those links; otherwise the Description is shown (or the URL if blank). |
| Research | Profile Information > **Research Interests**. A bulleted list is prefaced with a title. |
| Grants | Profile Information > **Grants**. Each line becomes an individual grant. |
| Services | Profile Information > **Academic Service**. Each line becomes an individual service. |
| Teaching Profile | Profile Information > **Teaching**. |

## Data added automatically

- **Publications** are added to your Publication list.
- **Activities** that are invited talks, seminars, or oral presentations are added to Presentations. Other activities are added to Key Professional Appointments.
- **Prizes** are added to Awards if you have not filled in Honors & Awards.
- **Keywords** are added to your Keyword list.

## How quickly changes appear

Changes in Illinois Experts are **not** shown in the directory immediately. They are picked up during the normal directory process and can take a few days. To force an update, open the **Biography** or **Activities** page in the directory and select **Refresh Directory Entry**.
