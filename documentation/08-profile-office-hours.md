# Set Your Profile Office Hours

## Summary

Set the days and times you are available. These appear on your profile.

**Path:** Profile Administration > Office Hours

## Steps

1. Open **Office Hours** from the left menu.
2. For each day of the week, enter a start time and end time.
3. Optionally choose a location type for the day.
4. Review the **Preview** line at the bottom.
5. Select **Save**.

## Rules

- If you leave **either** the opening or closing time blank, that day will **not** be displayed.
- Use the format `8:00 AM`.

## Location options

When a day has hours, you can choose:

- **Blank**
- **On Campus**
- **Remote**
- **Other** - enter a note. Use this if you work in more than one office, and name the office for that day.
