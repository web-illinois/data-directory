# Upload or Remove a Headshot

## Summary

Add a professional headshot to a profile and provide alternative text for accessibility.

**Path:** Profile Administration > Headshot

## Upload a headshot

1. Open **Headshot** from the left menu.
2. Upload your photo using the uploader.
3. Enter **Alternative Text for Headshot**.
4. Select **Save**.

### Image tips

- Crop the image before uploading. If it is not cropped, it will be automatically resized to a similar size.

## Replace a headshot

If a photo is already loaded, **delete the existing photo before uploading a new one**, then select **Save**.

## Alternative text

Alternative text is used for accessibility (for example, by screen readers).

- Describe the headshot as if you were describing it to someone on the phone.
- Do **not** use the phrases "photo of" or "picture of".
