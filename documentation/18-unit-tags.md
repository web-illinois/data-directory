# Manage Unit Tags

## Summary

Tags let you categorize people in your unit.

**Path:** Unit Administration > Tag Information

*Requires unit administrator access.*

## Existing tags

Tags **cannot be edited**. To change a tag, delete the old tag and add it again.

To remove a tag, select **Remove Tag** next to it.

> If a tag is removed, it may take a few hours for it to be removed from the directory repository. Names are added to a queue and processed at a regular interval. Check the logs to see if a name has been processed.

## Add a new tag

1. Enter a **Tag Name** (required).
2. Select **Can Employee Change this on Profile?** if employees should be able to add or remove the tag themselves.
3. Under **Who is this tag for?**, choose **No restrictions** or restrict the tag to a specific job type.
4. Select **Add New Tag**.
