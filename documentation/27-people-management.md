# People Management (Unit)

**Route:** `/unit/peoplemanagement`

Use this when the directory is not syncing with the information provided in the unit. If no unit is selected, a picker is shown first.

1. Enter the NetID of a unit administrator (without `@illinois.edu`).
2. Select **Send**. The NetID is sent to the directory along with the unit name.
3. A confirmation message or toast is displayed.

The **Send** button is disabled until a NetID is entered.
