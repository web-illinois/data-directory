# Upload or Remove a Resume / CV

## Summary

Attach a professional resume or CV to a profile.

**Path:** Profile Administration > Resume / CV

> **Important:** The CV is displayed on a **public website**. Remove personal information such as phone numbers and home addresses before uploading.

## Upload a document

1. Open **Resume / CV** from the left menu.
2. Upload your file using the uploader.
3. Select **Save Document**.

## Replace a document

If a CV is already loaded, **delete the existing CV before uploading a new one**, then select **Save Document**.
